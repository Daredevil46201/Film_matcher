# 🎬 Film Matcher — Выбор фильма для компании

## 📖 Описание
Консольное приложение на Python, которое помогает группе людей выбрать фильм на вечер. Программа поочерёдно опрашивает участников, собирает их предпочтения и находит фильмы, понравившиеся всем. Если совпадений несколько, запускается «Колесо фортуны» для финального выбора.

Проект создан в учебных целях для отработки модульной архитектуры, валидации ввода и работы с коллекциями данных.

## ✨ Возможности
- Поддержка любого количества участников
- Валидация ввода и защита от некорректных данных
- Команда `стоп` для досрочного завершения голосования
- Отображение метаданных фильма: жанр, год, рейтинг, режиссёр
- Два режима «Колеса фортуны»: мгновенный выбор или драматичное выбывание
- Модульная структура, готовая к подключению внешнего API

## 🛠 Технологии
- Python 3.12+
- Стандартная библиотека (`set`, `random`, `time`)
- Без внешних зависимостей (на текущем этапе)

# Film Matcher — Выбор фильма/сериала для компании

## Описание:
Консольное приложение на Python, которое помогает группе людей выбрать фильм/сериал на вечер. Программа поочерёдно опрашивает участников, собирает их предпочтения и находит фильмы, понравившиеся всем. Если совпадений несколько, запускается режим "Колесо фортуны" где выбирается режим "Случайный победитель" или "Русская рулетка" для получения финалиста.

## Функциональность:
- Выбор между фильмами и сериалами
- Фильтрация по рейтингу
- Исключение нежелательных жанров 
- Поддержка любого количества участников
- Валидация ввода и защита от некорректных данных
- Случайная выборка фильмов из TMDB API
- Команда `стоп` для досрочного завершения голосования
- Два режима «Колеса фортуны»: Случайный победитель" или "Русская рулетка"
- Отображение постеров фильмов

## Требования:
- Python 3.10+
- Аккаунт на TMDB (для получения API ключа)
- Библиотеки:
   - requests
   - python-dotenv

## Установка:
1. Клонируйте репозиторий:
   git clone [url]

2. Установите зависимости:
   pip install -r requirements.txt

3. Создайте файл .env в корне проекта:
   API_KEY=ваш_ключ_tmdb
   IP_proxie=ip_адрес_прокси

4. Получите API ключ на https://www.themoviedb.org/

## Использование:
Запуск программы:
python main.py

Программа предложит:
1. Выбрать тип контента (фильмы/сериалы)
2. Ввести количество участников
3. Для каждого участника:
   - Указать минимальный рейтинг
   - Указать год отсчёта
   - Выбрать исключаемые жанры
4. Пройти голосование по предложенным фильмам
5. Определить победителя с помощью "Колеса фортуны"

## Структура проекта:
- main.py — главный файл, точка входа
- api_client.py — работа с TMDB API
- core.py — функции ввода и голосования
- wheel.py — логика колеса фортуны
- .env — переменные окружения (API ключ, прокси)

## Технологии:
- Python 3.12
- TMDB API — база данных фильмов
- requests — HTTP запросы
- python-dotenv — управление переменными окружения
- random — генерация случайных чисел
